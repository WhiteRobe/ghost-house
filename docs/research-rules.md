# 《山中小屋》（Betrayal at House on the Hill）规则调研

> 调研日期：2026-11-17。依据第 3 版官方规则书（F4541，Avalon Hill 2022）和第 2 版规则书（F3148，2020 重印）全文，加上粉丝 Wiki、BGG、评测文章。拿不准的地方标「待核实」。
> 本文只为提炼**机制**。剧本、卡牌、角色的原文一律不抄，项目内容全部原创（见 PLAN.md 第 9 节）。

---

## 0. 速览：第 2 版和第 3 版的区别

| 项目 | 第 2 版 | 第 3 版（2022） |
|---|---|---|
| 作祟检定 | 抽到预兆的回合结束时掷 6 颗骰，总和 < 已抽预兆数就触发 | 抽到预兆**立刻**掷「已抽预兆数」颗骰，总和 ≥ 5 就触发；最后一张预兆必定触发 |
| 剧本怎么定 | 作祟表：预兆 × 抽到它的房间 | 开局选剧本卡；作祟时用「剧本卡 × 预兆」查表；另有 5 个剧本由特定事件卡触发 |
| 卡牌 | 预兆 13 / 物品 22 / 事件 45 | 预兆 9 / 物品 22 / 事件 43，另有 5 张剧本卡 |
| 房间 | 44 块 + 1 块三格入口板 | 42 块 + 3 块起始板 |
| 抢物品 | 造成 ≥2 点物理伤害时可以改抢物品 | 取消，改成搜刮尸体 |
| 发现房间 | 抽卡后停止移动，还能做别的 | 放下新房间就结束回合（先结算板块，再抽卡） |
| 信息 | 双方分开读书，目标保密 | 引言和设置公开朗读；规则一旦用过，对方可以要求公开原文 |
| 术语 | 漏洞多，靠房规 | 新增 General 伤害、heal、bury、critical、special action、视线等，歧义少 |

**结论：用第 3 版的规则框架**，第 2 版的经典作祟检定做成可选项。

来源：[第 3 版规则书 PDF](https://www.qugs.org/rules/r358504.pdf)、[第 2 版 Hasbro F3148](https://instructions.hasbro.com/en-us/instruction/avalon-hill-betrayal-at-house-on-the-hill-second-edition-cooperative-board-game)、[Wikipedia](https://en.wikipedia.org/wiki/Betrayal_at_House_on_the_Hill)、[Wargamer 第 3 版评测](https://www.wargamer.com/betrayal-at-house-on-the-hill/3rd-edition-review)

## 1. 组件

### 1.1 第 3 版内容物
- 6 块双面角色板，共 12 名探险者（同一块板两面不能同时上场）
- 8 颗专用骰，每颗面为 **0/0/1/1/2/2**
- 74 张卡：预兆 9、物品 22、事件 43；5 张剧本卡
- 3 块起始板：一楼三格大板（楼梯 / 走廊 / 门厅）、地下室平台、二楼平台
- 42 块房间板块，3 层：地下室、一楼、二楼（屋顶只在第 2 版扩展 Widow's Walk 里出现）
- 计数轨（Number Track）、114 个标记、两本作祟书（英雄方 / 叛徒方）

### 1.2 属性
- 四项属性：**速度、力量**（物理），**知识、理智**（精神）。
- 每条轨 = 1 个骷髅格 + 8 个数值格，数值可以重复（如 3,3,4…）。绿色格是起始值，最低数值格叫 critical。
- 伤害和成长都**按格移动**，不是按数值加减，所以数值重复时移一格可能数值不变。
- **治疗（heal）**：回到起始格；已在起始格或以上则不变。
- 示例（粉丝 Wiki，粗体为起始）：速度 3,3,**4**,5,6,6,7,8；力量 2,3,4,4,**5**,6,7,8。
- 先手：生日离今天最近的人，之后顺时针。

### 1.3 死亡
- **作祟前不会死**：属性最多降到最低数值格。第 3 版补充：还有别的属性能降时，不能把伤害放到已经 critical 的属性上。
- 作祟后任一属性降到骷髅格即死亡。第 3 版留下尸体，手牌留在尸体上。

### 1.4 骰子
- 检定：掷「当前属性值」颗骰（最多 8 颗）求和，对照「X+」或结果表。
- 伤害骰：「受到 N 骰物理伤害」= 掷 N 颗骰，点数即伤害。

### 1.5 房间板块与楼层
- 板块背面印着可放置的楼层（可以多个）。抽到的不属于当前楼层就放到牌堆底，继续抽。
- 新板块至少一扇门和来时的门对上；其余对不上的门是「假门」，不能通行。
- **每层必须始终留有至少一个开放门口**，会封死这一层的放法要换。
- 某层板块抽完后该层不能再探索；第 3 版规定探索失败不消耗移动。
- 跨层连接：一楼楼梯 ↔ 二楼平台；走廊 ↔ 地下室密梯；部分房间成对「通往」（如墓园 ↔ 地下洞穴）。
- 第 3 版房间符号分布（按 Wiki 统计，待核实）：预兆 14 块、事件 15 块、物品 6 块、无符号 7 块。**预兆房间多于预兆卡**，这是「最后一张预兆必定作祟」能成立的前提。

## 2. 回合流程（作祟前，第 3 版）

以下行动顺序任意、可以穿插、都不是必须的：
1. **移动**：最多走「回合开始时的速度」格；回合中速度变化不影响本回合。每格必须穿过双方都有的门。
2. **交易**：每回合 1 次，与同格玩家双方同意即可。本回合用过特殊行动或攻击过的物品不能交出。
3. **特殊行动**：物品 / 预兆上的能力，每种每回合 1 次；回合开始时不在手里的卡不能用。
4. **发现新房间**（固定六步）：抽板块（楼层不符放牌堆底再抽）→ 对齐门 → 棋子进入 → 结算板块文字 → 按板块符号抽对应的卡 → **回合结束**。
- 被迫移动「最多 X 格」时由执行方决定距离。

卡牌处理：事件朗读并结算（检定只读自己结果那一行），然后放牌堆底；物品和预兆正面朝上归自己所有。

## 3. 作祟检定与剧本选择

### 3.1 第 3 版（采用）
- 抽到预兆立刻掷「全场已抽预兆数」颗骰，**≥ 5** 触发，掷骰者成为揭示者。最后一张预兆自动触发。
- 触发概率（按 0/0/1/1/2/2 骰面计算）：

| 第 N 张预兆 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
|---|---|---|---|---|---|---|---|---|---|
| 触发概率 | 0 | 0 | 14.8% | 38.3% | 60.5% | 77.0% | 87.5% | 93.6% | 100% |

- **剧本卡**：开局从 5 张里选 1 张作为探索动机。作祟时在这张卡上查「刚抽到的预兆」→ 剧本号 + 叛徒规则。5 × 9 = 45 个，另 5 个由特定事件卡直接触发，共 50 个。
- **叛徒规则**类型：揭示者本人 / 揭示者左侧 / 某属性最高或最低（含或不含揭示者）/ 持有某物者 / 无叛徒 / 隐藏叛徒。同分取离揭示者最近的人。
- **自愿叛徒**：其他玩家可以自愿顶替。

### 3.2 第 2 版（可选模式）
- 抽到预兆的回合结束时掷 6 颗骰，总和 < 已抽预兆数就触发。第 5 张时约 23%，第 8 张约 77%，13 张必触发。
- 作祟表：预兆 × 发现该预兆的房间 → 剧本号。

## 4. 作祟之后

### 4.1 开场
- 第 3 版：英雄方公开读引言并设置 → 叛徒方公开读引言并设置 → 双方分开读其余内容（特殊规则、特殊行动、目标）。
- **秘密只保持到使用前**：一旦执行某条规则或行动，对方可以要求看原文。线上版正好做成「执行即公开到日志」。
- 作祟开始后不再做作祟检定。

### 4.2 回合顺序
- 从叛徒左手边开始，英雄依次行动，然后叛徒，然后叛徒的怪物（第 3 版由怪物卡的摆放位置决定，通常紧跟叛徒，待核实）。叛徒死后怪物仍可行动。

### 4.3 战斗
- 每回合攻击 1 次，目标在同格。双方掷力量（或指定属性），**高者对低者造成差值伤害**，平局无事。防守方赢了也伤害攻击方。
- 力量 / 速度攻击造成物理伤害（落在力量、速度上）；知识 / 理智攻击造成精神伤害；第 3 版还有 General 伤害（受伤者自选属性）。伤害在对应两项属性间任意分配。
- 武器：每次攻击只用 1 件，防守不能用；本回合刚拿到的武器不能用于攻击。
- 远程：视线 = 从一格出发不转向、不换层的直线。
- 第 3 版无抢物品；与尸体同格时每回合可以拿走 1 件物品或预兆。
- **阻碍**（第 3 版）：所在格有敌人或障碍时，离开要花 2 点移动，不叠加。被眩晕的怪物不阻碍。

### 4.4 叛徒特权
- 可以忽略房间的有害效果（坠落、灼伤等），但传送和滑道仍然生效。
- 可以选择不抽 / 不受事件影响。

### 4.5 怪物
- 属性固定。通常杀不死，受伤就**眩晕**（翻面），下回合开始翻回并跳过该回合。
- 移动：回合开始掷「速度」颗骰决定步数，至少 1 格；同类怪物共享一次掷骰。
- 默认用力量攻击，不能探索新房间，不能持有物品，忽略房间有害效果。

### 4.6 剧本类型与胜利
- 第 3 版 4 类：无叛徒（全员合作）、单叛徒、隐藏叛徒、大乱斗。
- 先完成己方目标的一方获胜。数值按人数缩放 `{3人/4人/5人/6人}`，计数轨用来累计。

## 5. 房间特殊效果（只分机制类型）

| 机制 | 说明 |
|---|---|
| 发现时一次性加属性 | 四种属性各有一间（每人每局一次） |
| 发现时检索牌堆 | 翻牌直到出现某类物品；或把某个特殊房间放到指定楼层 |
| 回合结束时伤害 | 在此结束回合受 1 点伤害 |
| 回合结束时检定坠落 | 速度检定失败 → 掉到地下室平台并受 1 骰伤害 |
| 滑道 | 结束回合在此（或进入即）滑到下层 |
| 随机传送房 | 掷 2 骰查表决定去哪层，整块板一起移动 |
| 屏障房 | 一分为二，穿越要属性检定，每回合一次，失败本回合停 |
| 障碍标记 | 离开花 2 点移动 |
| 远距相连 | 楼梯、成对房间 |
| 单向通道 | 可以选择跳到下层某房间 |
| 双物品 / 金库 | 高价值，需检定开启 |

## 6. 剧本结构与常见胜利条件

### 6.1 单个剧本的结构（第 3 版）
1. 识别：编号、触发条件、叛徒规则（两本书相同，用于校对）
2. 引言与设置：放标记、放怪物、改造房子、指定先手
3. 主体：特殊规则（全局 / 事件触发）、特殊行动（每回合每种 1 次）
4. 其他：目标摘要、标记清单、关键房间清单、胜利文本
5. 怪物框（仅叛徒方）：属性、特殊能力

### 6.2 胜利条件模式（自行归纳）
击杀（全部英雄 / 叛徒 / Boss，Boss 常需先满足条件）· 收集递送 · 仪式累积（某房间检定累计 N 次成功）· 逃脱 · 倒计时 · 生存 N 轮 · 护送保护 · 转化感染（死者加入叛徒）· 地形改造 · 隐藏身份 · 大乱斗 · 规则改写。

## 8. 实现要点

**引擎可以完全自动化**：属性轨与伤害分配（作祟前不死、critical 约束）、骰子与检定、地图（楼层堆、旋转与门对齐、假门、每层留口、远距相连、传送与滑道）、回合约束（速度锁定、交易一次、特殊行动去重、回合开始手牌快照、发现即结束回合）、牌堆、作祟检定与查表、叛徒规则求值、战斗 / 武器 / 视线 / 阻碍、怪物移动与眩晕、尸体搜刮、叛徒特权、按阵营隐藏信息。

**需要用 DSL 数据化**：剧本（元数据、设置、常驻修改器、事件钩子、特殊行动、怪物、胜利条件、文本）；物品 / 事件 / 房间效果复用同一套效果原语（约 30–50 个）。

**需要人工裁定**：保留房主「手动调整」按钮（改属性、挪棋子），记入日志。

## 9. 版权

- 机制本身一般不受著作权保护；规则书文字、卡牌与剧本文本、美术、角色设定受保护（[美国版权局 FL-108](https://www.copyright.gov/fls/fl108.pdf)）。「Betrayal at House on the Hill」「Avalon Hill」是 Hasbro 商标。
- 必须原创：游戏名与术语、全部角色（含属性轨数值）、全部卡牌、全部剧本、有辨识度的房间、美术和版式。通用房间名（厨房、书房）可以用。
- 粉丝 Wiki 和 GitHub 项目里的内容数据不能导入。
