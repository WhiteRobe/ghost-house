# 文案规范：去掉 AI 味

游戏里的字分两种，写法不一样：

- **规则文字**（卡牌 text、房间规则、剧本 goal / rules、按钮、提示）：像桌游说明书。短句，动词开头，数字用阿拉伯数字，术语统一。玩家要靠它算清楚能不能做、做了会怎样。
- **氛围文字**（flavor、房间描述、引言 intro、胜利文本 win、探险者简介）：像一个会讲鬼故事的人随口说出来。具体、短、有一个能看见或听见的细节就够了。

## 必须改掉的写法

1. **「不是 A，而是 B」「与其说……不如说……」「这不仅是……更是……」**：直接说 B。
2. **结尾升华的一句话**：例如「这一夜，注定无人入眠。」「有些门，一旦打开就关不上了。」删掉，故事停在最后一个具体动作上。
3. **破折号成串**：一段最多一个「——」，能用逗号、句号就用逗号、句号。
4. **凑三个**：「阴冷、潮湿、死寂」「哭声、笑声、脚步声」这种排比，留一个最具体的。
5. **AI 高频词**：仿佛、宛如、似乎、一丝、缓缓、悄然、无声地、弥漫着、诉说着、低语、透着、映照、交织、静静地、空气中、某种、莫名的、说不清的、命运、宿命、深渊、吞噬。偶尔用一个可以，一段里出现两个以上就改。
6. **空泛的恐怖形容**：「令人毛骨悚然」「诡异的气氛」「不祥的预感」。换成具体的东西：门缝里塞着一缕头发，比「诡异」吓人。
7. **人格化的房子 / 黑暗**：「房子在注视着你」「黑暗吞噬了一切」少用；真要用，就写得具体（楼梯自己多出了一级）。
8. **翻译腔**：「一个……的存在」「进行了一次检定」「对……造成伤害」可以保留在规则里（术语），氛围文字里改成口语。
9. **对仗工整的四字格连用**：「阴风阵阵、鬼影重重」。

## 规则文字的统一说法

- 「进行力量 4+ 检定」→ 写成「力量检定 4+」。
- 「受到 1 点物理伤害」「失去 1 点理智」：受到伤害可以减免，失去不能，按代码实际用的写。
- 「每回合一次」「每人每局一次」「回合结束时在这里」「发现这个房间时」：固定这几种说法。
- 「你」指持卡人或当前玩家。不要写「玩家」「该探险者」。
- 句末不加「哦」「呢」「吧」。

## 例子

| 改前 | 改后 |
|---|---|
| 空气中弥漫着一股莫名的腐朽气息，仿佛有什么东西正在黑暗中静静地注视着你。 | 一股烂木头味。床底下有东西挪了一下。 |
| 这不仅仅是一面镜子，更是通往另一个世界的入口。 | 镜子里的房间比外面多一扇门。 |
| 最后一张喜字被撕成碎片，花轿“噗”地烧成了灰。唢呐声戛然而止，一切归于寂静。 | 最后一张喜字撕下来，花轿“噗”地烧成了灰，唢呐卡在半个音上没了。 |
| 理智检定。4+：你定了定神，理智 +1。 | 理智检定 4+：理智 +1。失败：受到 1 点精神伤害。 |

## 改写时不能动的东西

- 所有 id、数值、骰数、门槛、机制。规则文字必须和代码行为一致；发现文字和代码不符，以代码为准改文字。
- 角色名、房间名、卡名可以小改（更顺口），但 id 不能改。
- 改完跑 `npx tsc --noEmit` 和 `npx vitest run`。
